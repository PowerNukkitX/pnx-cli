# 🚀 PowerNukkitX CLI 1.1.0 + PowerNukkitX Assistant 2.2.0

Two releases today: the **CLI** gets a big update, and a brand-new **desktop app** joins the family.

## ⌨️ `pnx` CLI 1.1.0
- **Plugin marketplace** from the hub: `pnx plugin list | search | info | install | update | remove`. Only hub-approved releases, checked against their SHA-256
- `pnx link` pairs your server with a hub
- `pnx update` upgrades PowerNukkitX itself, `pnx doctor` checks Java, disk and ports
- `--json` everywhere for scripts, a clearer help screen with "did you mean…"
```
npm install -g @powernukkitx/cli
```

## 🖥️ NEW: PowerNukkitX Assistant
Create and run a Bedrock server **without touching a terminal**. Windows, Linux and macOS, in 🇬🇧 🇫🇷 🇪🇸 🇩🇪 🇧🇷.
- **Create a server in ~2 minutes**: on your PC, or **on your Linux VPS over SSH** (Java 21 + a systemd service installed for you)
- **Live console** with search, filters and quick commands, plus a **players panel** (op, kick, ban, allow list, broadcast)
- **Plugin catalogue**: one-click install, updates, enable/disable
- **Visual `pnx.yml` editor**, no YAML to learn
- **Hot backups** (no downtime), automatic backups with rotation, and a **daily restart** announced in chat
- **Health checks** (Java, port, RAM, version), crash auto-restart, desktop notifications
- **Multi-server**, one-click PowerNukkitX core updates, `Ctrl+K` command palette, light/dark + 7 accents
